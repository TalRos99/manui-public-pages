# Manui public pages

Static pages for the Manui app, served by GitHub Pages
(Settings → Pages → Deploy from branch → `main` / root):

| Page               | URL                                                   | Used as                              |
| ------------------ | ----------------------------------------------------- | ------------------------------------ |
| `privacy/`         | https://talros99.github.io/manui-public-pages/privacy/  | Privacy Policy URL (both stores)     |
| `support/`         | https://talros99.github.io/manui-public-pages/support/  | Support URL (App Store Connect)      |
| `download/`        | https://talros99.github.io/manui-public-pages/download/ | Download link (sample pass QR code)  |

The source of truth is `docs/` in the app repo; copy changes from there.
